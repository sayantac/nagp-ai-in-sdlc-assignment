## How I used AI

- **Delegated to Claude Code:** mapping the code with a read-only subagent, drafting diagrams through the Mermaid MCP, extracting PayEx evidence, laying out the exactly-once options, running the three stress tests, critiquing my ADR, running 72 review evals headlessly, and drafting the audit.
- **Decided and signed off by me:** the choice of option D, which critique points to accept, the answer-key verdicts (drafted with AI assistance, then cross-checked and reviewed), the autonomy levels, and the audit decision.
- **Controls I built:** read-only subagents, deny rules, a guard hook on `ops/`, hook-based logging of every prompt and tool call, and a commit trailer linking each commit to a log entry.
- **Where the agent failed:** five wrong line numbers in its first citations (caught by a stricter verifier), an invented ApprovalService-to-DiscountCalculator edge in the unscoped run, and ungrounded cost numbers. It did not cave to a stated preference for a weaker option.
- **What I would change:** write the answer key with a second, independent reviewer; add subtler eval cases, because my set was at its ceiling and could not show improvement.
